unly_scenario

Код:
1578 if persistent.unly_spr_ch == 2:
        show unl wonder pioneer
     else:
        show unl wonder pioneer

В первом случае unl_n.

Код:
1765 hide unl

Наверное, и hide unl_n нужно.

Код:
1774 show credits unl_ at a:

Вылетает. Должно быть unl_ata.

Код:
1840 if persistent.unly_spr_ch == 2:
        show unl_n serious pioneer far
        show unl serious pioneer far

Не хватает else.

unly_res

Код:
696 image unl_n shade s = im.MatrixColor(im.Composite((900, 1080), (0, 0), get_unl_sprites_normal('unl_1_body.png'), (0, 0), get_unl_sprites_normal('unl_1_normal.png')), im.matrix.tint(0.01, 0.01, 0.01) )

Нужно unl_3_body.png и unl_3_pioneer.png, иначе силуэт не соответствует цветному спрайту.

Код:
698 image unl_n shade = im.MatrixColor(im.Composite((900, 1080), (0, 0), get_unl_sprites_normal('unl_1_body.png'), (0, 0), get_unl_sprites_normal('unl_1_normal.png')), im.matrix.tint(0.01, 0.01, 0.01) )
