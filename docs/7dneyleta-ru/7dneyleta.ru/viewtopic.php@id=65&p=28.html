Так теперь он больше не задаёт вопросов.

"А почему кошочка ... ?" - см. выше
"А почему Славя ... ?" - читать и больше не брать дурных примеров с дурных людей.
"А почему Ольга ... ?" - same shit.
"А почему Леначька ... ?" - same shit.
"Так не бывает, зуб даю!!!111одинодин" - автору виднее.
