Steam Workshop-версия.
Файл alt_day3.rpy. Условие
if persistent.un_7dl_good: // строка 10511
В этом условии на строке 10559 определяются две переменные. При невыполнении самого условия на строке 10758 получаем вылет в traceback с ошибкой undefined name. Решение "для себя" - перетащить определение этих двух переменных на строку до if. Это не влияет на проверки в других местах.

Заранее извиняюсь за самодеятельность и за то, если это где-то выше уже указано. Правил на скорую руку.
